## 🚨 POSIBLES PROBLEMAS

| Problema | Solución |
|----------|----------|
| Botón "Exportar" no aparece | Verificar import en página de detalle |
| Excel descarga como CSV | Instalar `npm install xlsx@latest` |
| PDF abre en nueva ventana | Instalar `npm install html2pdf@latest` |
| Cron no se ejecuta a las 4 PM | Verificar zona horaria del servidor |
| Logs no aparecen | `mkdir -p logs && chmod 755 logs` |
| Worker no actualiza precios | Verificar activos en BD + Yahoo Finance |
