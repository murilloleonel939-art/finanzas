1️⃣  CÓDIGO BACKEND (840 líneas)
═══════════════════════════════════════════════════════════════════════════════

📄 src/lib/precios-sync.js (193 líneas)
   ├─ Motor de sincronización de precios
   ├─ Agrupa activos por (tipo, ticker)
   ├─ Consulta Yahoo con deduplicación
   ├─ Registra precios en precios_activo
   ├─ Actualiza valor_unitario en activos_broker
   ├─ Maneja errores sin abortar
   ├─ Exporta: sincronizarPrecios, agruparActivosUnicos, registrarPrecio
   └─ Decisiones: D28, D29, D30 documentadas en comentarios

📄 src/lib/yahoo-finance.js (366 líneas)
   ├─ Cliente de Yahoo Finance API
   ├─ Endpoint: v8/finance/chart (público, sin auth)
   ├─ Concurrencia limitada a 5 simultáneas
   ├─ Validación de tipo de activo
   ├─ Headers con User-Agent navegador
   ├─ Exporta: obtenerPrecioYahoo, obtenerPreciosYahoo, validarTicker
   ├─ Constantes: ENDPOINT, CONCURRENCIA, CABECERAS, DIVISA_CRIPTO
   └─ Documentado: Por qué v8 en vez de v7, D29 validación

📄 worker-precios.mjs (312 líneas)
   ├─ Consumer de cola de jobs
   ├─ Se ejecuta cada 5 minutos (cron) o webhook
   ├─ Lee jobs con estado = 'pendiente'
   ├─ Obtiene activos por empresa/broker
   ├─ Ejecuta sincronizarPrecios() para cada job
   ├─ Guarda resultado en precios_jobs
   ├─ Marca como 'completado' o 'error'
   ├─ Usa Supabase SDK
   ├─ Exporta: ejecutarCiclo, procesarJob
   └─ Entry point: if (import.meta.url === ...) ejecutarCiclo()

2️⃣  API (EDGE FUNCTION)
═══════════════════════════════════════════════════════════════════════════════

📄 supabase/functions/actualizar-precios/index.ts (158 líneas)
   ├─ Endpoint HTTP POST
   ├─ Autenticación: JWT Bearer token
   ├─ Autorización: Solo super_admin (RLS policy)
   ├─ Ruta: POST /actualizar-precios
   ├─ Payload: { empresa_id: uuid, broker_id?: uuid }
   ├─ Response 201: { job_id: uuid, estado: "pendiente" }
   ├─ Response 401: Sin autenticación
   ├─ Response 403: No es super_admin
   ├─ Response 404: Empresa no existe
   ├─ Response 400: Parámetros inválidos
   ├─ Lógica:
   │  ├─ Valida JWT
   │  ├─ Verifica is_super_admin()
   │  ├─ Valida empresa existe
   │  ├─ Valida broker pertenece a empresa (si se pasa)
   │  └─ Encola en precios_jobs
   └─ Reutiliza patrón de D27 (import_jobs)

3️⃣  BASE DE DATOS
═══════════════════════════════════════════════════════════════════════════════

📄 supabase/migrations/0009_precios_jobs.sql (134 líneas)
   │
   ├─ TABLA: precios_jobs
   │  ├─ id: uuid (PK, default gen_random_uuid())
   │  ├─ empresa_id: uuid (FK → empresas, on delete cascade)
   │  ├─ broker_id: uuid (FK → brokers, on delete cascade, nullable)
   │  ├─ estado: public.estado_job (pendiente|procesando|completado|error)
   │  ├─ activos_totales: integer (default 0)
   │  ├─ activos_actualizados: integer (default 0)
   │  ├─ errores: integer (default 0)
   │  ├─ detalles: jsonb [{ nombre_activo, tipo_activo, ok, motivo }]
   │  ├─ error_mensaje: text
   │  ├─ intentos: integer (default 0)
   │  ├─ started_at: timestamptz (nullable)
   │  ├─ finished_at: timestamptz (nullable)
   │  ├─ created_by: uuid (FK → auth.users, on delete set null)
   │  ├─ created_at: timestamptz (default now())
   │  └─ updated_at: timestamptz (default now())
   │
   ├─ ÍNDICES
   │  ├─ precios_jobs_pendientes_idx
   │  │  └─ ON (estado, created_at) WHERE estado IN ('pendiente', 'procesando')
   │  │     [Búsqueda rápida de jobs no terminados]
   │  │
   │  └─ precios_jobs_empresa_idx
   │     └─ ON (empresa_id, created_at desc)
   │        [Historial por empresa]
   │
   ├─ TRIGGER
   │  └─ trg_precios_jobs_updated_at
   │     └─ BEFORE UPDATE → set_updated_at()
   │        [Actualiza updated_at automáticamente]
   │
   ├─ RLS (Row Level Security)
   │  ├─ ALTER TABLE precios_jobs ENABLE ROW LEVEL SECURITY
   │  │
   │  ├─ Policy: precios_jobs_select
   │  │  ├─ FOR SELECT TO authenticated
   │  │  └─ USING (has_empresa_access(empresa_id))
   │  │     [Usuario ve progreso de actualizaciones que pidió]
   │  │
   │  ├─ Policy: precios_jobs_insert
   │  │  ├─ FOR INSERT TO authenticated
   │  │  └─ WITH CHECK (is_super_admin() AND has_empresa_access(empresa_id))
   │  │     [Solo super_admin encola]
   │  │
   │  ├─ Policy: precios_jobs_update
   │  │  ├─ FOR UPDATE TO authenticated
   │  │  └─ USING/WITH CHECK (is_super_admin() AND has_empresa_access(empresa_id))
   │  │     [Solo super_admin actualiza/cancela]
   │  │
   │  └─ Policy: precios_jobs_delete
   │     ├─ FOR DELETE TO authenticated
   │     └─ USING (is_super_admin() AND has_empresa_access(empresa_id))
   │        [Solo super_admin elimina]
   │
   └─ REALTIME
      └─ ALTER PUBLICATION supabase_realtime ADD TABLE precios_jobs
         [UI ve cambios sin refresh]
