## 📌 Qué Se Hizo

### 1. Exportación de Datos (PRD §9.1)

Botón **"Exportar"** en tres páginas:

```
CuentaDetail   → Movimientos  (CSV / Excel / PDF)
WalletDetail   → Transacciones (CSV / Excel / PDF)
BrokerDetail   → Posiciones    (CSV / Excel / PDF)
```

**Componente:** `ExportButtons.jsx` (reutilizable, 195 líneas)

Métodos:
- `exportarCSV()` — UTF-8 con BOM, compatible Excel
- `exportarExcel()` — XLSX con formato (negrita + fondo gris)
- `exportarPDF()` — Tabla con bordes + fecha

### 2. Automatización a las 4 PM (PRD §9.2)

El sistema **actualiza precios automáticamente cada día a las 16:00 hora Colombia**.

**Cómo:**
1. `scripts/cron-setup.sh` instala cron en el servidor
2. A las 21:00 UTC (= 16:00 UTC-5) ejecuta `worker-precios.mjs`
3. Barre todos los activos de todas las empresas
4. Logs en `logs/cron-precios.log`

**Setup en producción:**
```bash
bash scripts/cron-setup.sh
```

## 🎯 Decisiones de Diseño

### D32 — Exportación de datos en CSV, Excel y PDF

- Componente reutilizable `ExportButtons.jsx`
- Props: `datos`, `columnas`, `nombreArchivo`, `disabled`
- Tres métodos de descarga sin dependencias externas (excepto `xlsx` para Excel con formato)
- Integración en CuentaDetail, WalletDetail, BrokerDetail

### D33 — Programación con cron del sistema

- Usa cron de Linux en lugar de setTimeout/intervalo
- Ejecuta a las 21:00 UTC (= 16:00 UTC-5 Colombia)
- Script `cron-setup.sh` automatiza la instalación
- Logs en `logs/cron-precios.log`
- Si el servidor está apagado a las 4 PM, NO recupera automáticamente

## 📝 Notas Importantes

1. **CSV siempre funciona** — sin dependencias externas
2. **Excel con formato** — requiere `npm install xlsx@latest`
3. **PDF** — requiere `html2pdf` o `jsPDF`, sino abre en nueva ventana
4. **Cron no es "catch-up"** — si el servidor está apagado a las 4 PM, no se recupera
5. **Hora en Colombia** — cron usa 21:00 UTC (UTC-5), el worker valida con `Intl`
